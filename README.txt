UMAR & AYESHA — LUXURY DIGITAL WEDDING INVITATION

HOW TO OPEN
1. Keep index.html and the assets folder together.
2. Open index.html in a modern browser, or upload the complete folder contents to GitHub Pages.
3. On GitHub, index.html must remain in the repository root and the assets folder must remain beside it.

IMPORTANT
- Music starts directly from the guest’s “Tap to open” gesture, with MP3 and AAC/M4A sources for broad browser compatibility.
- If a browser still blocks playback, the top-right control expands to “Tap for music”; one tap retries playback.
- Upload both files inside assets/audio with the rest of the folder. Missing that folder will prevent music from loading.
- Google Maps is the only venue navigation option.
- The U & A monogram is sourced from the supplied “Umar & Ayesha Logo.pdf” concept collection.
- The countdown unlocks only after the guest pulls the golden seal across the ribbon or uses the accessible instant-reveal option.
- Replace any image with your own photograph by keeping the same filename and dimensions/orientation where possible.
- Upload the extracted files and folders, not the ZIP file itself, when updating GitHub Pages.
